# 시장조사 방법론

## 조사 단위

기본 조사 단위는 "앱 기회 후보"입니다. 후보는 단순 아이디어가 아니라 다음 필드를 가진 구조화 객체입니다.

- 문제 진술
- 타깃 사용자
- 현재 대체재
- 핵심 사용 장면
- 예상 입력
- 예상 결과
- 수익화 모델
- 우선 시장: global_first, korea_localized, korea_first
- 경쟁앱
- 수요 증거
- 반증 증거
- MVP 범위
- 정책/법적 리스크
- 남는 모듈

## 조사 프레임

### 1. 수요 발견

수요는 하나의 소스로 판단하지 않습니다. 최소 2개 이상의 독립 신호가 필요합니다.

- 검색 신호: Google Trends, 키워드 도구, 자동완성, 관련 검색어
- 구매/지불 신호: 외주의뢰, 유료앱, 인앱구매, 구독앱, 템플릿 구매
- 불만 신호: Google Play 1-3성 리뷰, Reddit/커뮤니티 불만, 경쟁앱 리뷰
- 반복 사용 신호: 매일/매주 돌아올 이유, 알림/기록/관리 니즈
- 로컬라이즈 신호: 해외에서 검증됐지만 한국/특정 언어권에 약한 앱

### 2. 문제 검증

각 후보는 JTBD 관점으로 정리합니다.

- When: 사용자가 언제 이 문제를 만나는가?
- Situation: 어떤 상황/제약이 있는가?
- Motivation: 어떤 진전을 원하나?
- Outcome: 사용자가 얻고 싶은 결과는 무엇인가?
- Current workaround: 지금은 무엇으로 때우고 있나?

### 3. 경쟁 분석

경쟁앱은 단순 다운로드 수보다 "빈틈"을 봅니다.

- 상위 경쟁앱의 포지셔닝
- 최근 업데이트 빈도
- 리뷰 수와 평점 분포
- 1-3성 리뷰의 반복 불만
- 가격/광고/구독 구조
- 스토어 설명의 핵심 키워드
- UX 복잡도와 MVP 절단 가능성

### 4. 수익화 분석

초기 수익화 1순위는 광고형 안드로이드 앱입니다. 다른 수익모델은 보조 점수로 남기되, 기본 랭킹은 광고 수익화 가능성을 더 강하게 반영합니다.

- 광고 적합성: 세션 빈도, 체류 시간, 광고 삽입 지점, 국가/사용자군
- 구독 적합성: 반복 가치, 누적 데이터, 프리미엄 기능, 전환 명분
- 유료앱 적합성: 즉시 해결 가치, 비교 가능한 유료 대체재
- B2B/템플릿 적합성: 재사용 모듈, 업종별 커스터마이징, 개발자 수요

광고 적합성은 다음을 별도 평가합니다.

- 타깃 국가의 광고 단가 추정
- 고 eCPM권 국가에서 자연스러운 수요가 있는지 여부
- 광고주가 입찰할 만한 사용자군인지 여부
- DAU 없이도 초기 실험이 가능한 노출 구조
- 전면광고/배너/리워드 광고 중 자연스러운 삽입 지점
- 앱 출시 초기효과를 활용할 수 있는 검색/스토어 키워드 존재

광고형 앱은 두 유형을 모두 허용합니다.

- 반복 사용형: 매일/매주 재방문 이유가 있고 누적 사용량으로 광고 노출을 만든다.
- 일회성 해결형: 검색/스토어 유입으로 특정 문제를 빠르게 해결하고, 결과 생성 전후에 자연스러운 광고 지점이 있다.

### 5. 실행 가능성 분석

2주 MVP 가능성은 기능 수가 아니라 불확실성으로 판단합니다.

- 핵심 기능이 단일 입력-단일 결과로 줄어드는가?
- 서버 없이 또는 저비용 BaaS로 가능한가?
- 결제/인증/민감 개인정보를 초기 버전에서 피할 수 있는가?
- Android 정책 리스크가 낮은가?
- 디자인/스토어 자산 제작 난이도가 낮은가?
- 실패해도 공통 모듈이 남는가?

### 6. 제외 카테고리

다음 카테고리는 초기 범위에서 제외합니다.

- 성인
- 도박

정책/법률/사회적 리스크가 큰 카테고리는 별도 승인 없이는 보류합니다.

### 7. 신뢰도와 반증

각 결론은 신뢰도를 가집니다.

- A: 복수 독립 소스와 정량 신호가 일치
- B: 복수 소스는 있으나 정량성이 약함
- C: 단일 강한 소스 또는 여러 약한 소스
- D: 가설 수준

보고서에는 반증 신호도 같이 기록합니다.

- 검색량은 있지만 유료 전환 근거가 없음
- 불만은 많지만 해결 의지가 낮음
- 경쟁앱이 이미 무료로 충분히 잘 해결
- 정책/개인정보/저작권 리스크가 큼
- 광고 수익을 만들 만큼 반복 사용이 어려움

## 점수 초안

총점은 의사결정 보조용이며, 반드시 세부 점수와 같이 봅니다.

| 축 | 설명 | 기본 가중치 |
| --- | --- | --- |
| Demand Strength | 수요 신호의 강도와 독립성 | 25 |
| Ad Monetization Fit | 광고형 안드로이드 앱 수익화 적합성 | 25 |
| MVP Feasibility | 2주 내 단일 목적 앱 가능성 | 20 |
| Competitive Gap | 경쟁앱의 빈틈과 차별화 가능성 | 15 |
| High-eCPM Market Fit | 고 eCPM권에서 접근 가능한 시장성 | 10 |
| Retention Potential | 매일/매주 재방문 이유 | 10 |
| Asset Reusability | 실패해도 남는 모듈/템플릿 가치 | 5 |
| Risk Penalty | 정책/법률/데이터/플랫폼 리스크 | -20 to 0 |
