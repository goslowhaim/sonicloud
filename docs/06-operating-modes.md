# 운영 모드

## 1. 서치 테마

서치 테마는 넓게 탐색하는 모드입니다.

목표:

- 매일 앱 후보 10개 생성
- 매주 최소 1개 이상 실제 MVP 착수 가치가 있는 후보 도출
- 고 eCPM권 글로벌 시장의 광고형 안드로이드 앱을 우선 랭킹
- 한국 로컬라이즈 기회도 보조 후보로 포함

보고서 구조:

- 오늘의 Top 10 후보
- 상위 3개 상세 분석
- MVP 착수 후보
- 광고 수익화 가정
- 경쟁앱 빈틈
- 탈락 후보와 탈락 사유
- 다음 검증 액션

후보 필터:

- 성인, 도박 제외
- Android 출시 가능
- 2주 MVP 가능성 있음
- 광고 삽입 지점이 자연스러움
- 반복 사용형 또는 일회성 검색유입형 중 하나로 광고 노출 구조가 설명됨
- 글로벌 시장 또는 한국 로컬라이즈 가능성 있음

## 2. 집중 테마

집중 테마는 사용자가 지정한 하나의 주제를 최소 2주 동안 추적하는 모드입니다.

목표:

- 주제 관련 벤치마크 앱 추적
- 시장동향과 키워드 변화 추적
- 경쟁앱 리뷰/업데이트/가격 변화 추적
- 개발 중 의사결정에 필요한 인사이트 제공
- PRD, 기능 우선순위, 스토어 전략, 광고 전략 개선

보고서 구조:

- 오늘의 핵심 변화
- 벤치마크 앱 변화
- 사용자 불만/리뷰 패턴
- 기능/UX 패턴
- 광고 수익화 힌트
- 개발 결정에 주는 영향
- 내일 확인할 질문

집중 테마에서는 새 후보 수보다 누적 맥락이 중요합니다. 같은 주제를 반복 조사하면서 어제와 다른 점, 가설이 강화된 점, 약해진 점을 추적합니다.

## 모드 전환 규칙

- 기본 모드는 서치 테마입니다.
- 초기에는 집중 테마 없이 서치 테마로 시작합니다.
- 사용자가 주제를 지정하면 집중 테마로 전환합니다.
- 집중 테마는 사용자가 변경을 요청하기 전까지 최소 2주 동안 유지합니다.
- 집중 테마 중에도 주 1회는 서치 테마 요약을 얕게 병행할 수 있습니다.

## 첫 운영 가정

- 시장 우선순위: 고 eCPM권 글로벌 퍼스트
- 보조 전략: 해외 검증 앱의 한국 로컬라이즈
- 수익화 우선순위: 광고형 안드로이드 앱
- 광고 앱 유형: 반복 사용형과 일회성 검색유입형 모두 허용
- 초기 집중 테마: 없음
- 실제 앱 MVP 제작 의향: 있음
- 제외 카테고리: 성인, 도박
