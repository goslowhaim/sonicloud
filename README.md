# Android App Market Research Pipeline

매일 배치로 "안드로이드에서 출시 가능한 수익화 앱" 후보를 발굴, 검증, 점수화하고 보고서로 만드는 시장조사 시스템 기획 저장소입니다.

이 프로젝트의 핵심 전제는 LLM이 웹검색 결과를 요약하는 수준이 아닙니다. 전문 시장조사 절차를 파이프라인화하고, 각 단계의 증거 품질과 판단 품질을 하네스로 측정해 점진적으로 개선하는 것을 목표로 합니다.

## 목표

- 매일 신규 앱 기회 후보를 수집한다.
- 서치 테마에서는 매일 후보 10개를 만들고, 매주 1개 이상 실제 MVP 착수 가치가 있는 후보를 찾는다.
- 집중 테마에서는 사용자가 정한 주제를 최소 2주 동안 추적하며 개발에 필요한 벤치마크, 시장동향, 경쟁앱 변화, 수익화 인사이트를 매일 제공한다.
- 유효한 시장조사 대상에서만 정보를 추출한다.
- 수요, 지불의사, 경쟁 강도, MVP 난이도, 수익화 가능성, 정책 리스크를 분리 평가한다.
- 모든 결론에 근거, 출처, 신뢰도, 반증 가능성을 남긴다.
- 조사 파이프라인 자체를 테스트/평가/회귀검증 가능한 시스템으로 만든다.

## 초기 원칙

- "아이디어"가 아니라 "검증 가능한 기회"를 생산한다.
- LLM은 판단자가 아니라 추출기, 분류기, 가설 생성기, 보고서 작성 보조자로 제한한다.
- 출처 없는 결론은 보고서에 싣지 않는다.
- 단일 점수보다 점수의 구성요소와 불확실성을 더 중요하게 본다.
- 매일의 보고서는 누적 데이터베이스를 개선해야 한다.
- 초기 수익화 우선순위는 글로벌 퍼스트 광고형 안드로이드 앱이다.
- 글로벌 퍼스트 중에서도 고 eCPM권 국가를 1순위로 본다.
- 광고형 앱은 반복 사용형과 일회성 검색유입형을 모두 허용한다.
- 초기 운영은 집중 테마 없이 서치 테마로 시작한다.
- 기본 의사결정은 무료/저비용 우선이다. 유료 데이터 소스는 기본값이 아니다.
- LLM 사용 비용도 무료/저비용 우선 원칙에 포함한다.
- 첫 구현은 실제 수집보다 오프라인 하네스를 먼저 만든다.
- 하네스용 샘플 데이터는 사용자가 채우는 방식이 아니라 프로젝트에서 직접 수집한다.
- 최종 보고서는 한국어로 작성한다. 원문 데이터가 영어여도 보고서 단계에서 한국어로 번역/정리한다.
- 성인, 도박 카테고리는 제외한다.
